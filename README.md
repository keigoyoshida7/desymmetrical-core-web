# De-symmetrical Adaptation · Web UI

**[Web UIを開く](https://keigoyoshida7.github.io/desymmetrical-adaptation-web/)** — ログインなしで利用できます。

影の解析、カメラ選択、ブラウザでの音響化、Max/Spat5の接続に対応。

[Max一式](https://keigoyoshida7.github.io/desymmetrical-adaptation-web/De-symmetrical-Max.zip) · [操作手順](https://keigoyoshida7.github.io/desymmetrical-adaptation-web/protocol.html#max)

カメラ画像は端末内で解析します。StreamDiffusionを明示的に選んだ場合だけ、設定した生成サービスに入力画像を送信します。

このリポジトリは配布ファイルを管理します。更新元のコミットは deployment.json を参照してください。
