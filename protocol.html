De-symmetrical Core / 操作と対応範囲

同じ影を4つの音組織で聴く

  1. テスト信号、カメラ、動画・画像を選びます。カメラでは明るい面で基準を取得してから影を入れます。入力は端末内で解析します。
  2. 「ブラウザで試聴」で開始。現在の波形は波形図の下に表示されます。従来版の基本波形はsin波です。
  3. 「解析値を固定して比較」で同じフレームを保持し、I〜IVの章を切り替えます。解析条件は固定中に変更できません。
  4. 各章の波形・組織方法・周波数帯・パルス密度・倍音の基音を変更できます。「この章の初期値」で選択中の章を戻します。
  5. 「4章の設定を書き出す」で設定、固定サンプルID、解析値、実際の音源値をJSON保存。各章の設定はブラウザ内にも保存します。「停止」で音・カメラ・外部送信を停止します。

4章の仮案

I：sin波、110–3520 Hz、連続する層。II：矩形波、220–1760 Hz、階調ごとに発音位相をずらすパルス。III：三角波、55–880 Hz、基音の整数倍と円周配置。IV：帯域ノイズ、800–8000 Hz、半影に応じた拡散。章と波形は独立して選べます。これは検討用の実装案です。

周波数帯は周期波の基音、ノイズの中心周波数を指定します。倍音やノイズの裾は帯域の外にも伸びます。音色ごとの知覚音量は揃えていないため、比較時は音量も調整してください。倍音設定の帯域内に整数倍の候補がない場合は、指定帯域を優先して量子化しません。

Coreの仕様と測定

Core EN v22の30階調＋比較1層、壁16ch＋アーム1ch＋Subに合わせています。7m角とスピーカー座標は仮値です。アーム位置は手動で、実機追従はしません。中央の線群は階調・密度・音源・音組織に反応する表現で、音響測定や実機の信号計ではありません。

暗い物体と影は単眼では完全に分離できません。半影幅は勾配による推定です。Voronoiは累積階調輪郭の凸包と鏡映した隣接種から求めます。資料の2台の影カメラ、訪問者追跡、物理ロボット、振動出力、LLMはこのブラウザ版にはありません。

ステレオと17.1ch

通常はステレオ試聴を選択します。17.1ch直接出力はブラウザに18ch以上の出力として認識される機器が必要です。1–16は壁、17はアーム、18はSub。Subは低域音源から100Hzローパス経由。スピーカーごとのゲイン・極性・遅延・EQは校正データで指定できます。ブラウザ内の距離重み付けと残響による試聴で、IRCAM Spat5のレンダリングとは別です。

従来のMaxパッチ

従来版Max一式は12.1ch・sin波専用です。Coreの4章・波形切替・18出力には対応していません。誤った波形やチャンネル数で鳴らさないよう、Core画面から旧パッチへの接続は無効にしています。Core用のMax統合には、書き出した音源データのwaveform / organization / pulseRate / pulseWidth / phaseOffsetと18ch配置を扱う受信・合成が必要です。

比較画像・StreamDiffusion

比較モードを選びます。「変形テスト」はローカル変形で、画像生成AIではありません。StreamDiffusionを明示的に選択した場合だけ、入力画像を指定したサービスに送信します。モデルは同梱していません。

POST /generate
{ "image": "data:image/jpeg;base64,...", "sourceId": "camera-42-...",
  "sourceAt": 1789300000000, "prompt": "...", "strength": 0.25 }

200 OK
{ "provider": "StreamDiffusion", "sourceId": "camera-42-...",
  "generatedId": "unique-result-id", "generatedAt": 1789300000300,
  "image": "data:image/png;base64,..." }

由来ID、5秒以内の鮮度、値域、独立した3回の比較を検査します。固定中は新たな生成を停止し、固定した比較を試聴用に使用します。depart / converge / holdはローカル規則で、ロボットへ指令しません。

記録

時刻・解析値・選択章・波形・設定・比較結果を端末内に最大10,000件保存します。カメラ画像は記録しません。JSONLで書き出せます。
