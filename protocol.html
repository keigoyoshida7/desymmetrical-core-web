接続仕様・使い方

カメラから音へ

  1. カメラを選択し「カメラを接続」。ブラウザとMacのカメラ許可を有効にします。マイクは使用しません。
  2. 影がない明るい面で「明るい基準を取得」。影を入れ、必要なら中央の解析範囲を絞ります。
  3. 16 / 64 / 256階調を選択。「ブラウザで試聴」で試聴します。暗い階調ほど低い周波数・低い高さへ写像します。
  4. 「停止」で入力・音・外部送信を止めます。記録は解析値だけで、画像は保存しません。

測定の意味

単眼カメラは暗い物体と影を完全には識別できません。階調はブラウザのRGBに基づきます。半影幅は勾配による推定値です。実寸入力は平面の単純な換算で、レンズや遠近の補正ではありません。

Voronoiは各累積階調の輪郭を凸包に変換し、辺を垂直二等分線とする隣接種を作って計算します。元の凹形状は輪郭表示に残ります。セルの重心・面積が音の位置・広がりに対応します。

Max / Spat5：①〜⑤の手順

Max一式をダウンロードし、フォルダー内の max/De-symmetrical-257-Spat5.maxpat をMax 9で開きます。Spat5が必要です。フォルダー構成はそのまま使います。

  1. ① 接続サービスを起動。ランプ点灯後「Web UIを開く」。ローカルUIは自動接続します。公開版では「Maxへ接続」。キー1でも起動できます。
  2. ② オーディオ設定で内蔵出力などを選択。キー2で設定を開けます。
  3. ③ DSPをON。実際のDSP状態ランプも確認。キー3で切り替えます。
  4. ④ ステレオ試聴／12.1chと音量。このMacだけの試聴はステレオ。マスター初期値は -24 dB。Web側の音量も反映されます。
  5. ⑤ 5秒テスト音でメーターを確認。キー5でも実行できます。Web入力が届くとテストを終了します。その後、Webでカメラ等の入力を選びます。

Maxに送るのは音源の制御値で、音はMax内で合成します。「ブラウザで試聴」はMax出力には不要です。STOP（キー0／Esc）でDSPもOFF。MaxがunlockedならCommand+Eでロックします。番号キーはパッチ前面、数値入力を終えてから使います。

受信は実際のMaxフレーム受信。Aは全音源の絶対値合計、BはSpat5の12出力、Cは選択モードの出力直前のピークです。WebにもMaxから実測値とフレーム番号が戻ります。送信成功だけでは「Max受信確認」にはなりません。-120 dBFSは無音表示です。

13本のメーターは校正後・マスター前。Cが動いても聞こえない時は②の出力デバイス、I/O Mappings、スピーカー側の音量を確認します。13ch出力には対応機器が必要です。EQは会場プロセッサで設定します。

接続先：WebSocket 127.0.0.1:8788 → OSC 9000、Maxからの返送9001。HTTPSページから接続できない場合は このMacの接続用UI を使用します。パッチの二重起動を避けてください。

StreamDiffusion HTTP

このモードを選んだ場合だけ、入力画像を設定した生成サービスへ送ります。モデルはWebページには同梱されません。外部サービスはCORSを設定し、次の形式を扱ってください。 

POST /generate
{
  "image": "data:image/jpeg;base64,...",
  "sourceId": "camera-42-...",
  "sourceAt": 1789300000000,
  "prompt": "Observe an Asama volcanic stone shadow...",
  "strength": 0.25
}

200 OK
{
  "provider": "StreamDiffusion",
  "sourceId": "camera-42-...",
  "generatedId": "unique-result-id",
  "generatedAt": 1789300000300,
  "image": "data:image/png;base64,..."
}

由来ID一致、5秒以内の鮮度、有限で範囲内の差分、3回の独立した結果を確認して採用します。比較像と対応した元の解析を記録し、現時点のライブ画像と取り違えません。「画像を読込」は静的な参照なので、生成由来の証拠として扱いません。

記録と限界

解析値はこのブラウザ内に最大10,000件保存し、古い順に入れ替えます。JSONLで書き出せます。リアル画像・生成画像は保存しません。公開の複数端末アーカイブではありません。

depart / converge / hold と次のプロンプトは、現在はローカルの規則で作成します。LLMではありません。ロボット・照明指令は出しません。資料の会場設備、24.6MP/Mono12カメラ、光学精度、部屋の測定、長期連続運転の実証は別途必要です。
